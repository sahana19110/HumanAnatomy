# 🧠 Human Anatomy – AR/VR Learning Experience

An interactive Human Anatomy project developed using **Unity and C#** to explore human anatomical structures through 3D visualization and immersive VR interactions.

## 📌 About the Project

Human Anatomy is an educational AR/VR project completed during an internship. It aims to make anatomy learning more interactive by allowing users to explore 3D anatomical models and access organ-specific information in an immersive environment.

## ✨ Key Features

- **3D Anatomy Visualization:** Explore human anatomical structures in a 3D environment.
- **Organ Selection:** Select and control the visibility of individual organs.
- **Organ Information:** View organ names and descriptions through interactive popups.
- **Audio Support:** Play audio associated with organ information.
- **Body Transparency Control:** Adjust body model transparency using a slider.
- **Brain Animation:** Interact with brain animations to explore its parts.
- **VR Navigation:** Navigate between the main menu, anatomy view, and brain view.

## 🛠️ Technologies Used

- Unity 6
- C#
- Meta XR SDK
- 3D Anatomical Models
- Unity UI

## 🚀 Getting Started

### Prerequisites

- Unity version compatible with the project settings
- Required Unity packages and dependencies
- Compatible VR headset and XR runtime for VR testing

### Setup Instructions

1. Clone or download this repository.
2. Open Unity Hub.
3. Select **Add Project from Disk** and choose the project folder.
4. Open the project using a compatible Unity version.
5. Allow Unity to resolve the required packages.
6. Open the appropriate scene.
7. Configure the XR runtime and compatible device before testing VR functionality.

## 💻 Implementation Details

The project includes the following C# scripts:

- `OrganVisibilityController.cs` — Manages organ visibility.
- `OrganPopupManager.cs` — Handles organ information popups and associated audio.
- `BodyTransparencyController.cs` — Controls body model transparency.
- `BrainAnimation.cs` — Handles brain animation controls.
- `MainUIManager.cs` — Manages navigation between project views.
